# STARFORGE · 星穹熔炉

**体素星际工厂** —— 一款纯浏览器运行的 Three.js 体素游戏：在球面星球上采矿、建造、研究科技、搭建自动化工厂，驾驶飞船冲出大气层、与空间站贸易、跃迁到无限随机星系。

> 🎬 **原作 / 灵感来源**：【DSV4灰测一款游戏迭代了几百次有多恐怖？】 https://www.bilibili.com/video/BV1EZKN6hE3H/

## ✨ 特性

- **球面体素星球**：程序化生成地形、洞穴、矿脉、村庄与遗迹；16 种生态（翠绿 / 荒漠 / 冰封 / 熔火 / 异星 / 海洋 / 晶簇 / 巨菌 / 灰烬 / 金珀 / 磁暴 / 荧光沼泽 / 盐晶 / 黑曜 / 红藓 / 蜂窝）。
- **生存 / 创造 / 三档难度**：氧气、危险防护、护盾、喷气背包、采矿激光充能；难度决定采集与合成产出倍率。
- **自动化工厂**：熔炉、采矿机、传送带（自动转弯 / 爬坡）、装配机、精炼厂，以及太阳能 / 风力 / 火力 / 核反应堆供电网。
- **太空与星系**：无缝进出大气层、小行星采氚、空间站停靠与贸易、购船换船、曲率跃迁到无限随机星系。
- **任务线**：21 步主线任务，引导从坠毁求生到飞出初始星系。
- **跨平台联机**：内置 Node.js 联机服务器（Windows / macOS / Linux 通用，零第三方依赖），支持聊天、玩家列表、一键传送、服务器权威昼夜、世界与人物数据持久化（类 Minecraft 专用服务器 / 无人深空联机体验）。
- **泰拉瑞亚式存档**：人物（外观 / 背包 / 科技 / 飞船）与世界（地形 / 机器 / 星系）分离存档，任意人物可进入任意世界；支持 JSON 导入 / 导出。
- **捏人系统**：创建人物时可自定义肤色、发型（6 种）、发色、制服、饰条、裤装、靴子、头盔与目镜共 9 处细节，3D 实时预览。
- **活灵活现的生物**：鹿 / 螃蟹 / 史莱姆等精模播放真实骨骼动画（行走 / 待机 / 死亡），村民与空间站站员四肢随行走摆动。

## 🚀 快速开始

### 单机游玩

无构建、零运行时依赖，直接用浏览器打开即可：

```bash
# Windows：双击 index.html，或
start index.html
```

也可以通过任意静态文件服务器打开（如 `npx serve`、VS Code Live Server 等）。

### 跨平台联机

需要 [Node.js](https://nodejs.org/)（≥ 18，运行测试本身也需要，几乎任何电脑都能装）：

1. **启动服务器**（任意一台电脑，三平台通用）：
   - Windows：双击 `start-server.bat`（或 `启动联机主机.bat`）
   - macOS / Linux：`sh start-server.sh`（或 `chmod +x start-server.sh` 后 `./start-server.sh`）
   - 或命令行：`node server.mjs`
2. **房主**：浏览器打开 `http://localhost:17888`，进入「⇄ 联机」→ 填昵称 →「创建房间」→ 开始游戏，世界自动上传到服务器。
3. **好友**：浏览器打开 `http://主机IP:17888`（无需拷贝文件），「⇄ 联机」→ 输入主机 IP →「加入房间」，自动进入同一世界。

**联机特性**（目标：Minecraft / 无人深空式体验）：

- **服务器拥有世界**：种子、全星球方块改动、机器、市场行情、地图标记、星系档案都由服务器持久保存；房主下线后世界依然存在，任何玩家随时加入。
- **玩家数据持久化**：每个人的背包 / 科技 / 飞船 / 外观 / 上次位置按名字保存在服务器，重进不丢装备。
- **聊天**：`Enter` 聊天（`/help`、`/list` 命令），加入 / 离开 / 世界事件有系统广播。
- **玩家列表**：`O` 打开，可一键传送到任意队友身边（地面 / 太空均可）。
- **昼夜同步**：服务器权威时间，所有玩家看到同一片星空。
- **机器状态同步**：熔炉燃料 / 进度、皮带上的物品等实时对齐。
- **生物同步**：生物按世界种子确定性生成，队友附近的生物位置 / 血量对齐，击杀全端同步。
- **多星球 / 多星系**：任何玩家在任何星球 / 星系建造，其他玩家到达时都能看到。

**服务器配置**：首次运行自动生成 `server-config.json`（端口 / 服务器名 / 欢迎语 / 密码 / 人数上限 / 存档目录 / 自动存档间隔），也可用命令行覆盖：

```bash
node server.mjs --name "我的服务器" --password 123 --max-players 16 --port-ws 17900
```

世界存档位于 `save/world.json`（自动保存 + Ctrl+C 优雅退出前存档）。删除该文件即可重置世界，或在游戏里由房主点「重置服务器世界」。

> 局域网提示：好友访问 `http://主机IP:17888` 时若无法打开，请在主机防火墙放行 TCP 17888 / 17889（Windows 首次运行会弹窗询问）。

## 🎮 操作

### 星球地面

| 键位 | 功能 |
|---|---|
| `W A S D` | 移动 |
| `空格` | 跳跃 / 长按喷气背包 |
| `鼠标左键` | 采矿激光（长按挖掘方块 / 攻击生物） |
| `鼠标右键` | 放置方块 / 建造机器（有虚影预览） |
| `R` | 旋转放置朝向 |
| `滚轮` / `0~9` | 切换快捷栏（`0` = 采矿激光固定位） |
| `E` | 交互（机器 / 飞船 / 面板） |
| `G` | 丢出手中物品（`Shift+G` 丢整组） |
| `C` | 扫描（地面矿物 / 飞行兴趣点 / 太空天体） |
| `M` | 星球地图 |
| `Tab` | 背包与合成 |
| `T` | 科技树 |
| `P` | 创造物品库（仅创造模式） |
| `F5` | 快速存档 |
| `Esc` | 系统菜单 |

### 飞船与太空

- `E` 登船入座 → `W` 点火起飞（自动加注燃料）。
- 大气层内：鼠标转向 · `A/D` 滚转 · `W/S` 油门 · `E` 就地降落。
- 太空：`A/D` 滚转 · `Shift` 超载 · `J` 脉冲引擎（消耗氚）。
- 曲速跃迁：太空中 `M` 星图锁定目标星系 → 出图对准方框 → `J` 脉冲冲刺达速自动跃迁。

### ⚠ 浏览器键位冲突说明

纯浏览器运行会与浏览器自带手势 / 快捷键产生少量冲突。代码已尽可能屏蔽（指针锁定 + 拦截右键菜单 / 中键），但**浏览器原生鼠标手势（Opera / Vivaldi）与鼠标手势扩展（如 crxMouse、SmartUp 等）运行在网页脚本之上，网页无法 100% 关闭**。若右键拖动仍触发「前进 / 后退」等手势，请任选其一：

- 关闭浏览器自带「鼠标手势」功能（Opera：设置 → 浏览器 → 快捷操作 → 鼠标手势）。
- 在鼠标手势扩展里把本游戏地址加入白名单 / 排除列表。
- 游玩时用 `F11` 全屏，减少边缘手势误触。

> 网页代码层面已处理：`contextmenu` / `auxclick` / 中键默认行为全部 `preventDefault`，进入游戏态后点击画面即进入指针锁定（pointer lock），锁定后鼠标移动转为原始增量、手势不再触发。

## 🧪 自动化测试

项目内置一套 Playwright 无头测试（加载 `index.html?test=1` 自动注入测试接口），覆盖游戏系统与联机协议（测试运行器会自动拉起一个隔离存档的联机服务器跑 `tests/12-net.js`）：

```bash
npm install            # 安装 playwright-core（仅几 MB，无需下载浏览器）
npm test               # 无头运行全套（需 Node ≥ 20 + Edge / Chrome）
npm run test:headed    # 有头模式可视化调试
```

> 完整的使用手册见 [TESTING.md](TESTING.md)。

## 📁 项目结构

```
├── index.html          # 入口（无构建，经典 <script>）
├── css/                # 样式
├── js/                 # 游戏逻辑（data / world / factory / player / space / station / net / ...）
├── test/               # Playwright 测试编排器 + 静态服务器
├── tests/              # 12 个测试套件（文件名排序 = 执行顺序，12 = 联机协议）
├── server.mjs          # 跨平台联机服务器（Node.js ≥ 18，零依赖：HTTP + WebSocket + 世界持久化）
├── server-config.json  # 服务器配置（首次运行自动生成）
├── start-server.bat    # Windows 一键启动服务器
├── start-server.sh     # macOS / Linux 一键启动服务器
└── 启动联机主机.bat      # 兼容旧名的启动入口（转调 start-server.bat）
```
