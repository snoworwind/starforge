# 边疆公会内容扩展与项目检查记录

本次检查以 `starforge-bevy` 为当前主工程，覆盖内容数据与可获取性、背包交易、主线/村庄任务、工厂产出、太空战斗、扫描、游戏调度、界面入口及角色/世界存档边界。旧 Web 目录是历史归档，不是本次扩展目标。

## 检查发现与改进

| 检查发现 | 本次改进 |
|---|---|
| 工厂和异星材料种类丰富，但两章主线之外的持续需求有限 | 30 种可循环补给单，将原料、生产部件、生命保障及晚期航天产品接入稳定需求 |
| 村庄支线完成后始终只显示感谢对话 | 支线完成后可继续领取新订单，需求随完成次数变化，并获得公会声望 |
| 扫描主要服务于定位矿物，缺少跨生态的收集目标 | 16 种实地调查，每种需要三处记录和对应物资，配有生态笔记 |
| 完成主线后缺少分支目标与长期进度展示 | 6 条独立远征、12 个里程碑、5 级声望及 HUD 追踪 |
| 新增多物资交付可能在发奖时遇到背包满 | 先在背包副本上扣除所有物资并装入奖励，全部成功才一次性提交 |
| 事件在帧前部读取，可能落后于同帧战斗、建设和保存 | 新增 `FrontierProgress` 调度阶段，位于玩法更新之后、界面领取和存档之前，保证阶段基线和保存快照完整 |
| 默认界面文字较暗，新增中文信息量大 | 公会使用独立的深色不透明面板、明亮文字、全宽内容卡片、滚动区域与进度条；使用可显示的 Cr 记号 |

## 可玩内容

### 补给委托

30 个手工编写的模板分为五级，委托方包括晨曦救援队、漂泊者营地、赤铜工坊、穹顶建筑社、远航邮局与天穹研究院。

- 委托板同时展示三个不同订单，最多接受三单。
- 未接受订单由当前星系、槽位和刷新次数确定；读档不会随机洗牌。
- 接受后记录固定模板，之后的升阶、研究、星系旅行不会修改该订单。
- 交付需要一次性提供角色背包中的全部需求，货仓/机器库存需先取出。
- 取消不返奖、不扣材料；完成或取消刷新该槽位。没有现实时间或游戏时间截止日期。
- 信用点奖励为 `80 + 需求物资基础市值 × 1.25`，研究数据为 `等级 + 1`，声望为 `8 + 等级 × 4`（内部等级从 0 开始）。
- 模板自身要求的科技以及交付成品的直接配方科技均需解锁。研究进度和声望共同决定可出现的订单。

### 远征故事

| 远征 | 解锁等级 | 玩法路径 |
|---|---|---|
| 长夜里的灯 | 见习拓荒者 | 应急补给 → 信标建设 → 首次生态调查 → 营地物资 |
| 沉默的流水线 | 见习拓荒者 | 冶金研究 → 批量金属 → 传送带建设 → 精密部件 |
| 无人应答的频率 | 边疆伙伴 | 搜救补给 → 空间站停泊 → 敌对海盗 → 医疗与氧气 |
| 群星的颜色 | 边疆伙伴 | 两种生态调查 → 二级扫描 → 冷热矿物 → 四种生态调查 |
| 遗迹的回声 | 资深开拓者 | 遗迹守卫 → 超导电路 → 异星生物材料 → 信标阵列 |
| 第二个家园 | 星际领航员 | 星系跃迁 → 定居物资 → 防御炮塔 → 殖民核心实际产出 |

每条四阶段。前三阶段分别奖励 200 信用点、2 研究数据、5 声望；终章奖励 `1200 + 解锁等级 × 400` 信用点、8 研究数据、30 声望。

交付阶段会消耗物资；建设/事件目标仅统计该阶段激活后的行为；研究和调查认可历史成果。多条路线可同时推进，切换追踪不重置阶段和领取记录。建设按放置行为统计，不要求方块永久保留；殖民远征最终要求真实产出，仅摆出机器不能完成终章。海盗目标沿用现有敌对舰船判定，和平访客不计入；炮塔协助击败的遗迹守卫计入防卫成果。

### 生态图鉴

所有 16 种现有生态都有调查条目。C 键沿用实际地面扫描的冷却，不增加额外按键。记录以地形种子和水平位置标识，同星球内两两至少相距 64m；每种生态最多保存三处有效样本。原地重复扫描、抬高高度或读档无法增加记录。

物资来自现有可采集资源：碳、沙、低温晶体、玄武岩碎片、孢子、树脂、铁矿、活性酶、盐晶与几丁质。危险生态奖励 450 信用点与 6 数据，安全生态奖励 250 信用点与 4 数据；每份报告均提供 15 声望。每种生态只能提交一次。

### 声望与里程碑

公会等级门槛为 0 / 40 / 120 / 260 / 500 声望，对应见习拓荒者、边疆伙伴、资深开拓者、星际领航员与星穹先驱。声望不作为消耗货币。

12 个里程碑覆盖完成 1/10/30 单，调查 1/8/16 种生态，完成 1/6 条远征，击败 5 艘海盗与 6 名守卫、完成 3 次跃迁，以及殖民核心完成 5 次产出。每项奖励必须手动领取且仅能领取一次。

## 存档与兼容

- `WorldData.frontier` 为带默认值的新增字段；旧版本 5 存档无需转换即可加载为空白公会记录。
- 公会进度跟随世界，沿用现有角色/世界配对保存与失败回滚机制。切换星球和星系不重置此字段。
- 保存订单模板 ID、槽位刷新次数、远征阶段及基线、声望、事件计数、调查点、已提交报告和已领取里程碑。
- 读档清理未知模板、重复接单槽位、非法调查点和未知事件/成就 ID。
- 四页终端仅是瞬时 UI；窗口选择不属于世界进度。原生联机沿用本地任务记录方式，本次没有新增共享团队任务协议。
- 旧存档无法还原过去的击杀/跃迁次数；这类里程碑从本版本开始记录。原有研究结果仍可满足远征条件。

## 验证

基线 106 项测试通过。扩展后的 120 项测试包括内容引用、全部模板可出现性、科技过滤、订单确定性、背包满与物资不足的整笔回滚、释放槽位发奖、死亡/创造模式保护、三点调查距离、六条远征完整推进、跨存档阶段基线、重复领奖保护、非法记录清理和真实 ECS 消息的一次性消费。

执行检查：

```powershell
cargo fmt --all -- --check
cargo check --locked --all-targets --all-features
cargo clippy --locked --all-targets --all-features -- -D warnings
cargo test --locked --all-targets --all-features
cargo run --locked -- --smoke
```

`--smoke` 现在还会轮流打开公会四个页面，再执行原有地面/太空检查和存档。可设置环境变量 `STARFORGE_SMOKE_CAPTURE` 为已有目录，自动导出四张界面截图用于视觉复核。此次本地截图和日志位于忽略的 `target/frontier-qa/`。

这些检查验证规则、集成与页面实际渲染；并未以人工从零生存游玩方式完成全部晚期路线。高级委托的经济节奏与 16 生态全集收集时长仍适合后续长期试玩调整。
