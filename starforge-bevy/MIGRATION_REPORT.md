# STARFORGE Bevy 最终迁移核对报告

**核对日期**：2026-08-17

**主工程**：`starforge-bevy/`（Rust 2024 + Bevy 0.19.1）

**旧版归档**：`legacy-web/`（Three.js + Node.js，仅作历史参考）

**结论**：主线迁移完成；旧协议兼容不在 Bevy 版范围内。

## 1. 本轮全面核对范围

逐模块检查了 `src/` 的 App 生命周期、世界生成、玩家、背包、工厂、生物、任务、太空、空间站、UI、音频、存档、材质和程序化纹理，并把旧 Web 版的源码、服务器、测试与脚本整体移入 `legacy-web/`。根目录现在只承载 Bevy 主工程、迁移规格、许可证和两个版本的 CI。

本轮还修正了旧报告与实际代码不一致的问题。旧报告曾把太空战斗、地图、天气、访客舰队和护盾列为缺失项，这些项现在均已在 Bevy 中实现。

## 2. 最后一轮完成项

### 气候与行星视觉

- 新增 16 种生态对应的雨、雪、灰烬、孢子、沙尘等天气粒子；
- 新增随玩家循环的高空云团；
- 新增太空可见的程序化行星云层，并处理经度接缝；
- 云层和天气可在设置中独立关闭并持久化；
- 加入生态覆盖单元测试。

### 空间站与访客交通

- 访客舰队拥有巡航、进站、停靠、离站四阶段状态机；
- 三个停机位带占用管理，毁船和离站都会可靠释放；
- 飞船激光使用线段扫掠碰撞，降低高速穿透；
- 空间站受击升起可视护盾并关闭泊入口，倒计时结束后恢复；
- 护盾开启时玩家泊入会被明确阻止和提示。

### 星图与曲速视觉

- 星系图由列表升级为缓慢旋转的 3D 投影星域；
- 55 个邻域星系按深度投影，支持悬停、选择、已访问着色与跃迁锁定；
- 曲速阶段新增 180 条局部空间发光星线，长度和速度随点火阶段变化；
- 原有姿态、加速、跨星系档案和抵达流程保持不变。

### Bevy 原生联机

- 新增完全独立于旧 Node.js 协议的权威 UDP 主机/客户端；
- 同一 Bevy 可执行程序可创建主机或加入主机，`O` 打开联机面板；
- 支持最多 32 人、世界指纹校验、位置/模式快照、远端角色插值、在线列表和聊天；
- 方块与机器放置/拆除以增量同步，主机保存会话增量供迟加入玩家回放；
- 对名字、聊天、坐标、方块、包长、协议版本和连接超时做边界校验；
- 增加真实双客户端集成测试，覆盖登录、双人快照、聊天和方块中继。

### 仓库收尾

- 旧版整体移动到 `legacy-web/`，包括仅供移植核对的 JS 黄金值生成器；相对资源路径和启动脚本仍可在归档目录内独立工作；
- CI 移除旧 Web 回归任务，只保留 Bevy 格式、全目标编译、严格 Clippy 和测试；
- 根目录新增中文 `README.md` 与英文 `README_EN.md`，互相链接；
- Bevy 详细 README、功能清单、键位和目录结构已同步。

## 4. 有意保留的边界

1. `legacy-web/` 是只读意义上的历史归档；Bevy 不加载其中的 JavaScript、HTML、Node 服务器或存档格式。
2. Bevy 原生联机要求各玩家读取相同世界，主机用世界与星系种子指纹拒绝错误世界；当前会话同步玩家、聊天和体素/机器放置增量，个人背包与人物存档仍由各客户端保存。
3. 视觉实现追求功能与风格等价，不要求 Three.js 场景节点、材质参数或 DOM 布局逐对象相同。
4. 数据表中保留了部分供后续内容扩展的字段和入口；这些未被当前运行路径读取的字段属于有意保留的移植接口。

冒烟流程实际覆盖建世界、地表实体与天气、存档、切换太空、区块隐藏和太空背景断言，再次存档后退出。旧 Web 归档的 45 个 JavaScript / MJS 文件也全部通过 `node --check`，且仓库中已没有散落在 `legacy-web/` 之外的 Web 版 JS/HTML/CSS；其 Playwright 浏览器套件仍需本机可用的 npm 与浏览器依赖。

## 6. 运行入口

```powershell
cd starforge-bevy
cargo run --release
```

- `O`：Bevy 原生联机；
- `M`：地表为星球地图，太空为 3D 投影星图；
- `cargo run -- --smoke`：自动冒烟验证。
