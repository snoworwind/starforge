## 1. 结论摘要

原版《星穹熔炉》是一款体量极大的体素星际工厂游戏（16 生态球面星球、自动化工厂、太空飞船、
空间站、曲率跃迁、21 步任务线、联机服务器）。第一阶段完成了单机地面玩法核心闭环；
**第二阶段完成太空与星际阶段**：飞船（登船/大气飞行/太空/脉冲引擎/再入）、无缝换系与多星球、

传送带物流、捏人与体素人形、像素风渲染模式。约 1.1 万行 Rust，编译零错误，测试全部通过。

**一句话**：从落地采矿到飞出初始星系——「第一章」全部内容已可完整游玩。

## 6. 与原版实现差异（有意为之）

1. 原版为 Web/IndexedDB 存档，本版为原生文件（`saves/` 目录）。
2. 原版用 Three.js `onBeforeCompile` 注入着色器，本版用 Bevy ExtendedMaterial 原生材质扩展。
3. 原版联机与存档服务器分离，本版暂为纯单机。
4. 原版太空星球为 LOD 球壳贴图（实时整球回绘 + 溶解），本版为程序化噪声贴图球体 + 大气光晕，
   接近时由体素地形无缝接管（无溶解过渡动画）。
5. 原版空间站内部为完整建模 + 访客舰队巡航 + 护盾系统，本版为程序化机库 + 静态游商船（对话/购船完整）。
6. 原版曲速跃迁有星系精灵贴图与曲速粒子，本版为速度飙升 + 硬锁镜头 + FOV 拉伸（时长一致 15.7s）。
7. 原版星球地图（M 全息球面）与信标 3D 标记未移植（星系地图以列表呈现）。
8. 原版"现代/像素"渲染风格为 CSS 缩放，本版为 Bevy 渲染目标 + ImageNode 最近邻放大（重启生效）。
9. 原版 JS 用可变时间步长，本版用 Bevy 帧时间（dt 上限由引擎控制）。

## 9. 运行方式

```powershell
cd starforge-bevy
cargo run --release     # 首次构建需编译依赖（约 10~30 分钟）
cargo test              # 回归测试（噪声黄金值/星系/换系/工厂/任务等）
cargo run -- --smoke    # 冒烟自测：自动建世界→游玩→切入太空→打印 SMOKE_OK 退出
```

游戏内：主菜单 → 新世界（可选生态/难度/种子/捏人）→ WASD 移动、左键采矿、右键放置、
Tab 背包合成、T 科技树、C 扫描、F5 存档。靠近飞船按 E 登船，W 点火起飞，拉升冲出大气层进入太空；
M 打开星系地图锁定目标，J 脉冲冲刺对准目标自动跃迁；飞向空间站自动泊入，站内 E 交易/购船/换船。
