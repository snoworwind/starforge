# 04 · 工厂、角色、生物、太空、特效与UI

对应H/I/J并衔接F。目标是让已有功能在游玩时能被看懂、有可信动作和统一艺术风格。所有状态表现来自权威业务状态；界面美化不能改交易、库存、研究或战斗规则。

## 4.1 工厂表现层拆分

1. 从 `factory.rs` 输出只读MachineVisualState；保留原生产tick、功耗、库存、流体逻辑，拆出mesh/socket/动画/声音/灯。
2. 建立按MachineKind索引的视觉注册表，含模型、材质、旋转、端口、动态部件、状态图标、破损/建造预览、LOD和fallback。
3. 逻辑占地仍以现有方块/机器定义为准；设备模型可以有外挑细节，但不要挡住合法相邻机器/通路。若必须改占地，进入显式玩法兼容变更。
4. 机器实体stable ID与位置/星球归属绑定；每次重载不重复建立灯和运输物件。外观热更新不重置进度和库存。
5. 运行状态优先级：损坏/禁用→无电→缺料→输出堵塞→工作→空闲→完成短提示。颜色、图标、部件动作和UI标签保持一致，不只红绿灯。
6. 动作由逻辑进度插值和有限平滑驱动：钻头只在有效工作时转，断电渐停可以是视觉惯性，但不能继续假装产物生成。

## 4.2 全机器美术清单

当前25个具体种类加Other。每项按“白盒轮廓→接口与碰撞→材质/动态件→状态→预览/LOD→停电/拥堵/重载验收”完成，不只换顶面贴图。

| 类型 | 必做构造和动态细节 | 状态/注意事项 |
| --- | --- | --- |
| Furnace 熔炉 | 炉膛、炉门、烟道、炉口光、少量火星 | 无燃料/缺矿停火；烟源在烟囱socket，不从机底冒 |
| Miner 矿机 | 底架、钻杆、传动、工作面粉尘 | 朝向/钻击与实际目标一致；无矿不持续打火 |
| Belt 传送带 | 带面、滚轮、边框、端头、弯段 | 速度反映实际运输；货物位置有连续性，堵塞可读 |
| Assembler 装配机 | 舱体、机械臂、观察窗、夹具 | 臂不穿舱；进度周期稳定，停机停动作 |
| Solar 太阳能 | 支架、电池板、接线盒 | 昼夜发电反馈一致；面朝太阳动画不改逻辑占地 |
| Refinery 精炼 | 双罐、管路、阀和工作窗 | 原料/成品方向明确，装饰管不误导网络连接 |
| Chest 箱 | 铰链、盖、锁扣、分类标牌 | 开盖不穿邻物；容量与库存标签来自真实数据 |
| Reactor 反应堆 | 核心罩、冷却环、警示带、蒸汽 | 辐光克制，失效不假发电；工作灯受电力状态 |
| Launchpad 发射台 | 平台分区、引导灯、定位标、坡道 | 占地/降落判定相同；起落架不陷地，边缘可达 |
| Wind 风机 | 塔身、机舱、叶片轴 | 风向/转速与天气合理；旋转bounds/影子同步 |
| Burner 燃烧器 | 料斗、燃烧口、烟筒 | 燃料耗尽视觉归零；烟量有上限 |
| Beacon 信标 | 塔体、灯头、底座、脉冲圈 | 远景可识别但不跨全图刺眼；地图符号同族 |
| Lumberbot 伐木机 | 底盘、机械臂、刀头、收纳位 | 作业/行走/回收三状态，刀头不打空中 |
| Collector 收集点 | 入口、托盘、状态屏 | 接收半径不靠巨大常驻光圈表示；选中时显示 |
| Medbay 医疗舱 | 床/舱、监护屏、治疗灯 | 无耗材或无电不播完成治疗；交互点留净空 |
| Splitter 分流 | 分叉带/门控、端口箭头 | 分流动画反映实际出口，不凭渲染帧轮转 |
| Filter 筛选 | 筛选头、物品小标、拒收灯 | 当前筛选图标可辨；改变筛选不丢物流视觉ID |
| Cable 电缆 | 直/弯/T/十字/端帽、支架 | 邻接mask来自电网拓扑；外观线不跨不存在的连接 |
| Battery 电池 | 模组、汇流条、充电指示 | 电量与充放电区分；低电有形状提示不单纯变红 |
| Pipe 管道 | 直/弯/T/交叉/阀/封口 | 类型/方向一致；不能视觉连接但逻辑不通 |
| Tank 储液罐 | 外壳、视液窗、顶接口 | 液面读取库存比例，缩放不穿壁 |
| Pump 泵 | 泵体、叶轮、输入输出接头 | 空转/断电/缺液区分，流体特效只在工作时 |
| Geothermal 地热 | 井口、隔热管、换热器 | 蒸汽与工作强度相关，支撑落地 |
| ColonyCore 殖民核心 | 控制舱、生命维持模块、天线 | 住房/供氧/供电/耗材不足各有明确状态 |
| Turret 炮塔 | 基座、转台、俯仰轴、枪口 | 目标方向/枪口弹道一致；转动不决定命中逻辑 |
| Other fallback | 中性占位箱+诊断标识 | 未注册类型不panic；发行前覆盖报告不能遗留漏项 |

### 物流和连接细节

1. 传送物件从固定彩色小方块升级为有类别轮廓的共享小模型/图标牌，最多显示受预算限制的代表物件，不能为每个库存单位生成Entity。
2. 将物件位置绑定逻辑段进度/稳定运输槽，过弯插值连续；低帧率、多人插值和暂停恢复不倒退抖动。
3. 远距离切带面动感和吞吐标识；不改变逻辑货物数量。物件离开可见区回收缓存，不生成可拾取实体。
4. 电缆/管道邻接变化只dirty自身及邻居连接件；拆除后端帽更新。垂直连接和跨chunk边界纳入测试。
5. 全机器建立统一工作灯管理，沿用D灯预算；细节烟雾/火花有距离和工作量LOD，不因100台机器同时开工溢出粒子预算。

## 4.3 建造、拆除与蓝图反馈

1. 用最终模型的简化预览替换一律方块虚影，显示真实朝向、端口、占地和旋转轴。蓝图显示边界、数量、成本和无法放置区域。
2. 合法/非法用颜色+符号+简短原因；色觉模式可辨。预览对太阳和Bloom保持稳定，不把半透明叠加到完全看不清地面。
3. 放置合法性由同一业务校验函数返回，不允许UI一套规则、右键另一套。网络等待中显示pending，不先播成功并扣两次材料。
4. 拆机/采矿按表面发碎屑、有限亮点、裂纹和进度；现有“挖掘不整屏闪”原则保留，采集反馈集中在目标附近。
5. 高亮轮廓要经过depth验证，透墙显示仅给明确扫描能力且不同样式；掉落物磁吸和拾取动画不影响实际拾取量。

## 4.4 角色外观与NPC

当前spawn_humanoid未使用Appearance，I01先建立外观字段到实际模型/材质的可用映射，列“不支持字段”清单，避免UI展示实际上无效的选择。

1. 选择统一科幻服装/体型基准，外部模型保留可用骨架和动作用作来源，服装、配色、配件统一加工；不原样混杂魔法职业服饰到科幻村庄。
2. Appearance字段分别映射肤色、发型/发色、制服、饰条、裤、靴、目镜/头盔。无可用mesh的发型先制作资产或明确在UI禁用，不接受静默no-op。
3. 捏人预览和世界实体共用一条组装管线；旋转/缩放不会改变角色存档。材质变体有界缓存，两个玩家不同肤色不互相覆盖。
4. 玩家第三人称与NPC必要装备有实际mesh/socket；第一人称手/工具视图作为可选增强，注意裁剪层、FOV与世界阴影的关系。
5. 骨骼/clip命名、根节点和forward轴标准化，导入检查idle/walk/run/turn/interact/hit/death。不要靠数字动画索引赌源模型顺序。
6. 步速和动画速度匹配，脚底接地；坡地优先有限脚部偏移/姿态矫正，完整IK仅在预算验证后扩展。动画不能移动权威碰撞体。
7. NPC注视、呼吸、小幅重心、工具操作按职责和状态，随机相位稳定，不所有NPC同步摇摆。远处降频/停次要动作，不影响逻辑。

验收：所有可选外观字段有实际前后效果；中文捏人UI可用；同场多个角色外观隔离；上下坡、坐站、受击、死亡、重载、联机插值不穿地或错绑动画。

## 4.5 生物与生态生命感

1. 按当前物种建立体型/步态/轮廓表；现有程序化生物增加关节层次、背脊/壳/角/毛簇，先确保重心和脚位置，再做表面细节。
2. 每类至少idle/walk/run/alert/hit/death，休息/觅食作为共享扩展。动作混合有最短保持时间，避免每帧状态抖动。
3. 步伐扬尘、脚印、水花和叫声由动作事件/接触事件触发；不是每帧按速度随机发粒子。不同地表用统一Surface标签。
4. 略微转头/群体朝向/环境互动增加生命感，但不改兽群spawn、击杀永久消失和资源掉落。模型LOD不能创建新生物记录。
5. 程序化颜色保持生态调性，眼/口/关节识别点在夜间可辨；危险单位有形状特征，不仅红色皮肤。
6. 淡入淡出和阴影同步，避免身体消失影子残留；skinned bounds覆盖动作最大范围，避免动物转身一半消失。

## 4.6 飞船与空间站

### 飞船

1. 对C/B/A/S建立可辨轮廓而非只换大小/贴图，统一金属/涂层/窗/能量通道。外部和程序化fallback以同一材质规范审稿。
2. 清理glTF层级和多余材质，绑定驾驶位、引擎、枪口、登船口、起落架、相机锚点；从真实bounds核对碰撞，不手猜统一缩放。
3. 加入起落架/舱门/姿态喷口/航行灯等有状态的细节：停泊、起飞、大气飞行、太空、加力、损伤和跃迁。无实际逻辑的开门动画不能允许穿透封闭碰撞。
4. 引擎尾流分喷口亮核、近场体积、远尾迹；根据油门/加力驱动，机体平移造成的粒子拖尾在世界空间积分，切坐标系时不拉成一条万米线。
5. 第一/第三人称切换保留视角连续和障碍避让；座舱玻璃不重复tone map，HUD层与玻璃透明合成分清。
6. 激光从真实枪口出发并与已有高速弹道命中吻合；光束只表现轨迹，不能从相机中心绕过船壳穿墙。
7. 远船用简化形体/灯点/标签，不每艘维持全套骨骼和尾焰。标签遮挡、距离单位和敌我图形统一。

### 空间站与轨道

1. 拆站体主题：主轮廓、结构梁、居住/工业舱、泊位和服务区。高频细节集中在玩家会接近的泊位与步行区。
2. 沿用当前站顶停泊入口和实际碰撞通道；优化模型时保留空洞与通道，不能用大凸包堵住可穿区域。
3. 加服务标牌、泊位编号、导航灯、停泊路径、舱内明暗层次、NPC活动与设备。贸易/换船终端位置和UI提示一致。
4. 护盾受击以接触点波纹/能量沿面扩散，不整站无限泛白；站体封锁时门禁/泊位提示与逻辑同步。
5. 行星贴图统一地貌采样，增加海陆粗糙度、冰盖、薄大气、昼夜过渡；夜间城市灯只对已存在/生成的聚落或合理轨道尺度代理，不随机暗示可访问大都市。
6. 小行星增加尺度/旋转/粗糙度变体、破碎截面、矿迹和少量碎屑；破碎VFX不改变一次掉落结算。
7. 星空/星云背景要给主体留明度空间；星云做低频构图且不随相机平移显示近景视差，避免背景抢占飞行导航。

## 4.7 VFX与镜头舒适度

现有ParticleStyle、缓存、上限、camera_fx和screen_fx继续使用，逐步抽统一VisualEvent接入，不另外加重复伤害/采矿监听器。

| 事件族 | 表现目标 | 具体限制 |
| --- | --- | --- |
| 采矿/破碎/放置 | 命中点亮屑、材质碎片、可读进度 | 不整屏闪；碎片有限寿命、离屏回收 |
| 脚步/落地/喷气 | 地表相关尘/水花、重量、方向感 | 根据接触节奏，低帧不连喷上百粒子 |
| 治疗/护盾 | 色彩和形状不同的局部反馈 | 不遮瞄准和氧气；完成与实际事件一致 |
| 枪火/爆炸/弹着 | 清楚起点终点、冲击层次、短灯 | 爆炸闪光/烟/碎片分预算；遮蔽危险提示 |
| 机器烟/蒸汽 | 从socket出发、随风、随负载 | 距离LOD和实体总预算，停机不持续出烟 |
| 雨/雪/灰/孢子 | 有方向和深度，室内遮挡 | 近镜头密度上限；不跟镜头旋转成固定网罩 |
| 扫描/发现/升级 | 焦点明确，信息分层 | 扫描透墙信息仅限能力授权；避免和地图叠满 |
| 再入/跃迁 | 速度与尺度感、连续过渡 | 相机晃动可关；非用户操作不突然翻滚 |

实施：重要性队列→距离/屏占比LOD→共享mesh/material→软粒子与depth fade→可选GPU路径。GPU粒子只在证据显示CPU粒子瓶颈时实施，先验证事件确定性、bounds、资源回收和低档fallback。

镜头由一个最终合成系统依次应用基础姿态、弹簧跟随、避障、FOV、头部摇晃/后坐/震动；“减少动态效果”分别控制震动、头晃、FOV脉动、闪光和模糊。短震动强度有总上限，多个事件叠加不会持续飘移。photo退出、死亡、重生、失焦要重置临时偏移。

## 4.8 UI改造架构

首选保留bevy_egui承担产品UI与调试界面，但分开样式和入口；先做theme/widgets和视图模型，再判断哪些高度特殊的HUD需要Bevy UI或自绘。没有可测收益不整体更换UI框架。

1. `theme`定义字体族、字号、行高、间距、圆角、描边、面板背景、颜色语义、焦点、动效时间和层级；所有产品面板共享。
2. `widgets`定义按钮、图标按钮、物品槽、资源条、标签、tooltip、tab、列表、搜索、过滤、空态、错误态、确认条、进度、通知、地图图钉。每组件有normal/hover/pressed/focused/disabled/loading。
3. `view_models`把业务数据转为只读展示，交互生成命令给现有业务处理；不能在绘制函数里新增重复扣费/领取逻辑。
4. `input_router`定义UI焦点、游戏鼠标锁定、快捷键、文本输入、模态优先级。保留现有手动egui begin/end pass唯一所有者，不能迁移一半后出现两次begin_pass。
5. 每帧临时计算与缓存明确区分；物品排序/图标列表/地图基底按数据revision更新，长列表虚拟化；tooltip不每帧复制整个库存。
6. 相机画质、像素渲染、窗口DPI与UI scale分开。UI在原生分辨率上排版，像素模式只影响3D，不把汉字缩成不可读点阵。

## 4.9 UI全界面实施清单

每个界面执行：信息层级线框→统一组件实现→空/满/错误/加载/禁用状态→输入焦点→1280/1920/超宽+DPI→真实业务回归→前后截图。不能用一个新HUD截图代表全部UI完成。

| 界面 | 结构和具体操作 | 边界/验收重点 |
| --- | --- | --- |
| 主菜单 | 清楚继续/新建/世界/角色/设置；轻量动态背景、版本 | 首次无存档、损坏档、后台加载；主菜单不维持整世界 |
| 世界/角色列表 | 卡片摘要、种子/进度/最后保存、预览 | 长名、重复名、备份恢复；删除沿既有安全流程 |
| 捏人 | 左预览右分组、随机/重置、实时可见变化 | 无效选项禁用说明、肤色非仅缩略图变化 |
| 加载 | 分阶段真实进度、当前步骤、资产失败说明 | 不用假进度100%卡住；失败有返回入口 |
| 地面HUD | 生命/氧气/护盾/危险、快捷栏、任务、准星分区 | 低氧优先于发现通知；装饰不占中心视线 |
| 飞行HUD | 姿态/速度/燃料/高度/目标/武器与模式 | 地面/太空单位清楚；锁定目标不丢；第一第三人称一致 |
| 背包/合成 | 网格、分类搜索、配方树、材料缺口、详情 | 拖拽/拆半/Shift/溢出/垃圾桶/F5保存物品守恒 |
| 科技树 | 分支布局、前置关系、成本、队列进度 | 锁定理由、长文本、缩放/键盘导航；不重复消费 |
| 机器面板 | 结构示意、输入/输出、配方/功率/效率/故障 | 真正无电/堵塞/缺液状态；交换物品不丢失 |
| 电力/流体信息 | 当前网络范围、产需/蓄电/流向 | 只展示实际连接网络，不能混合全星球总量 |
| 贸易 | 买卖分栏、数量/总价/余额/容量、明确提交 | 动态价格变更、容量不足、重复点击原子结算 |

| 空间站服务 | 服务分组、泊位/封锁状态、快捷入口 | 不能在受袭封锁时仍提示可离站/交易的错误状态 |

| 任务/公会 | 主线、委托、远征、调查、里程碑分层 | 领取前后数量/容量；长章节不遮按钮 |
| 图鉴 | 分类/搜索/发现度、图像/3D预览、资源用途 | 未发现剪影、缺图、分页；奖励只触发一次 |
| 成就 | 完成/进行/锁定、进度、领取/通知 | 通知限流；不挡紧急生存警报 |
| 联机 | 主机/加入、房间状态、在线列表、聊天 | 输入中文时游戏不采矿；断线/拒绝可理解 |
| 创造库/蓝图 | 分类搜索、完整模型预览、成本与旋转 | 大列表虚拟化；粘贴失败标明阻挡点 |

## 4.10 排版、交互与可访问性

1. 统一4/8单位间距网格，正文以16–18逻辑像素起、辅助文字不低于经验证的可读字号；对1280×720可折叠侧栏，超宽限制中心信息最大宽度。
2. Noto Sans SC作为中文fallback保留，英文字体/数字等宽策略单独选择；度量多语言实际宽度，不按字符串字节长度布局。动态字号不要无限生成不同font atlas尺寸。
3. 普通正文对比度目标4.5:1，大字3:1，依据 [WCAG 2.2对比度说明](https://www.w3.org/TR/WCAG22/#contrast-minimum)作为内部设计参考；同时测最亮雪地和最暗洞穴背景，不能只对纯黑面板测。
4. 焦点指示明确、Tab顺序与视觉顺序一致；键盘/鼠标先完整，手柄支持可分批但按钮提示需设备感知，不假称已全面支持。
5. tooltip延迟约0.3–0.5秒起、离开快速消失，自动避开鼠标/屏幕边界；长说明可固定面板，不能把核心操作只藏hover。
6. 核心状态至少颜色+图标/文本双编码；色觉模式、减少动态、字体缩放、闪光降低分别设置。
7. 输入法组合期间禁止处理聊天/命名快捷键为世界动作；Esc先退出组合/当前弹层，再关闭面板；Alt-Tab清按键和鼠标状态。
8. 通知队列按危险/任务/发现分优先级，去重、合并批量拾取，设置可见数量上限；低氧/受击始终优先。
9. 界面动效短且可打断，面板打开不延迟业务按钮可用；减少动态模式关闭滑动和缩放，保留清楚焦点反馈。
10. 不在游戏产品UI显示Rust类型名、shader路径、GPU buffer错误；高级诊断可展开。面向玩家说明“体积云暂不可用，已切换简化云”，开发日志再给技术原因。
