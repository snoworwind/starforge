## 交付契约

1. `SettingSpec` 注册表 `VISUAL_SETTING_SPECS`（23 个数值项 + bool/legacy 分类）：
   - 每项固定 key/label/unit/group/`ApplyMode`/`SettingValueKind`/min/max/default；范围即 loader 接受范围，UI 滑条范围由同一表推导（`spec().slider_range()`、`setting_slider_*`）。
   - `ApplyMode::Immediate/NextWorld/Restart/Legacy`；`pixelated` 标 Restart，`cloud_render_width/height` 标 Legacy 并在诊断里显式列出“已废弃，不影响渲染”（R061/R117）。
2. 单一校验入口 `sanitize_settings(&mut Settings) -> SanitizeReport`：
   - 非有限值回默认（`NonFinite`）、越界回 clamp（`OutOfRange`）、非法云分辨率回默认对（`UnsupportedValue`）；`previous` 用 `Option<f64>`，NaN/inf 不写入 JSON（避免序列化失败）。
   - `load_settings`/`save_settings` 都调用它；`load_settings_reported()` 额外保留整档解析失败标记（settings.json 存在但不可解析 → 默认值 + `fallback_to_defaults=true`）。
   - `CloudTuning::sanitize`/`LightingTuning::sanitize` 改为委托注册表，面板与文件范围不再有两份。
3. `VisualSettings`（`Settings.visual` 嵌套组，带 serde default，旧档无需迁移）：`task_capacity` 与 4 个资源告警阈值；`configure_visual_settings` 在 Startup 把 capacity 应用到 `VisualTaskRegistry`（Restart），并逐条 `warn!` 修复记录。
4. 预设/自定义/恢复默认：`apply_visual_preset(Low/Medium/High)` 只改成本相关字段（视距/云/天气/步数），不动美术调参；`detect_visual_preset` 支持 自定义；`reset_visual_settings` 只重置视觉字段，保留音量/灵敏度。
5. 统一诊断 `VisualDiagnostics`（A04 建议落地）：相机摘要 + `ResolvedQuality` + `VisualLifecycleDiagnostics` + 实际生效 `Settings` + preset + 加载报告 + 阈值告警 + inert 设置；`Last` 每帧更新；visual_qa 导出 `<run>-diagnostics.json`。
6. UI 接入（J05 前置）：暂停面板新增画质预设下拉与“恢复默认画质”，滑条范围/单位全部走注册表（渲染距离 3–32、灵敏度 0.05–5 等），新增折叠的“高级诊断”（任务/资产/告警/废弃项），产品层不显示类型名与 shader 路径。
