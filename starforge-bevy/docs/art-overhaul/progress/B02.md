## 交付内容

1. `src/art/catalog.rs`（新，B02 主交付）：显式、与注册顺序无关的材质目录
   - `SurfaceMaterialId`（`u16` 显式常量，1..=62；`UNKNOWN=0`）；`SURFACE_MATERIALS` 逐条含 key/`MaterialFamily`/`UV策略`/当前变体数/`SurfaceTag`/发光档；ID 1..62 冻结到旧 `textures.rs` painter 顺序，但**不再从顺序推导**；`data.rs` 的 u8 方块 ID 保持区块/存档 ABI。
   - `MaterialFamily`（13 族，来自 01 §1.4）带 roughness 范围、metallic 策略与 3–6 变体预算；`FaceRole`（Side/Top/Bottom/Front）与 `face_material`/`cross_material` 按 `Tiles::for_face` 语义解析，运行时用一次构建的 256 项 `FaceTable`（`OnceLock`）O(1) 查询，meshing 热路径无字符串/HashMap。
   - 变体规则 `variant_slot(material, variants, wx, y, wz, face)`：只用稳定整数世界格 + 层高 + 面 + 材质 ID（`rng::hash2_state`），禁止 Entity/加载顺序/帧号。
   - 冻结指纹 `id_fingerprint`/`face_fingerprint`（FNV-1a）与覆盖审计 `catalog_report()`（未知 tile、未知 biome 地表 key、有 painter 无材质、有材质无 painter 均为硬失败；`unused_materials` 单列）；`catalog_snapshot()` 输出 B03 用完整目录。
   - biome 地表映射 `ground_material` 冻结旧 `tile_key`（grass/snow/alien/murk/redmoss→`*_top`）。
2. `src/textures.rs`：`Atlas` 增加 `by_material` ID→UV 表与 `uv_rect_material`/`tile_material`/`catalog_gaps`；painter 列表拆为 `painters()`（单一来源），`Atlas::build()` 走 `from_painters` 并在 debug 下断言目录无缺口；新增测试钩子 `#[cfg(test)] build_with_order` 构造乱序图集；方块/交叉图标改为消费 `catalog::face_material`/`cross_material`（同上/侧/前 ID），不再直读 `Tiles` 字符串。
3. `src/world.rs`：meshing 两个 UV 取点收敛到 `surface_uv(atlas, SurfaceMaterialId)`；远景 `far_tile_avg` → `far_material_avg`，`far_surface_sample`/`fill_far_rows` 经 `catalog::ground_material` 解析（含三处旧 `tile_key` 删除）；行为与旧路径逐格一致。
4. `src/art/manifest.rs`：`ArtAuditReport` 增加 `catalog` 块（schema 1→2 附加字段），`failure_count` 纳入目录硬失败；`--art-audit` 打印 `ART_AUDIT_CATALOG ... id_fp/face_fp` 并新增 `target/art-audit/material-catalog.json`。
5. `visual_qa` run summary 增加 `catalog_version`/`catalog_id_fingerprint`/`catalog_face_fingerprint`，K05 不得跨指纹配对前后帧。
6. 文档：`art/style-guide.md` 新增 §3.1（ID/面角色/变体/审计/指纹规则）；README `--art-audit` 行与 QA 报告段说明材质目录与指纹。

- 回滚：删除 `src/art/catalog.rs`、还原 `textures.rs` 的 painter 拆分与图标取层、`world.rs` 的 `surface_uv`/`far_material_avg`、manifest 的 `catalog` 块与 CLI 打印、visual_qa summary 字段即可；无数据迁移。
- 已注入/已覆盖：未知 biome 地表 key、未知材质 key（`ground_material("not_a_tile")`→`UNKNOWN`）、乱序图集、空变体预算、cross/side 优先级、非法 face 索引、图标空图回归；`failure_count` 注入假未知 tile 后确实上升。
- 未注入：真实删除 painter（静态表不可注入，靠 debug 断言 + 反向测试覆盖）、纹理数组/压缩布局（尚不存在，B03）。
