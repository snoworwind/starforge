## 交付内容

1. `src/art/texture_pipeline.rs`（新，纯 CPU 生产线）
   - `ChannelClass::Albedo/LinearData/Normal`，各自正确缩小：Albedo 在**线性光 + 预乘 alpha**下平均（透明 texel 不拉黑边缘，R019）；LinearData 原样箱式平均；Normal 解码 xy、还原 z、平均后归一（R014/R022）。
   - 每材质 mip 链到 1×1；`preserve_alpha_coverage` 用按目标覆盖率缩放的 4×4 Bayer 有序抖动重映射 alpha，保持 `Mask(0.4)` 阈值覆盖率（主/影共用同一值，R016）；<4×4 的层级只报告。
   - `pad_tile`：gutter 从源分辨率 4 起精确减半（4/2/1），边缘 extrude；`build_padded_atlas` 每级独立打包，内层 UV 跨级一致（`uv_stable`）；`verify_bleed` 逐 padding 像素验证只含本 tile 内容（R013）。
   - `plan_array`/`plan_atlas` 字节预算；`decide_route` 路由 `TextureArray → PaddedAtlas → ClassicAtlas` 并给出拒绝原因；`contact_sheet_rgb` + 无依赖 24-bit `write_bmp`。
   - `texture_audit_report(low)` / `run_texture_audit(low)`：62 材质全量审计、覆盖率/法线合成校验、报告 JSON。
2. `RenderCapabilities`（A03 扩展）：`surface_color`（Rgba8UnormSrgb）与 `surface_bc7` 格式支持、`TEXTURE_COMPRESSION_BC/ETC2/ASTC` 特性、`max_texture_array_layers` 仿真；`texture_route(materials, base_size)` 与 `surface_compression()`；启动日志与 visual_qa `-capabilities.json` 记录实际路由与压缩选择（R012/R117）。
3. `--texture-audit` CLI（A06 `LaunchOptions`）：不开窗、不碰存档/GPU，写 `target/art-audit/texture-pipeline.json` 与 `texture-contact-sheet.bmp`，失败返回 2；`--simulate-low-device` 用低端参考限制验证 PaddedAtlas fallback。
4. 文档：`art/style-guide.md` §3.2（通道类/覆盖率/图集与数组/路由/验收）；README `--texture-audit` 与 capabilities 字段。
