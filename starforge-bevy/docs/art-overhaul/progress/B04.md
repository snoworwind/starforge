## 交付内容

1. `src/art/pbr.rs`（新，B04 主交付）
   - `PbrFamilyProfile`：13 家族逐条 roughness 基准/变化/metallic/法线强度/必做细节，全部落在 `MaterialFamily::roughness_range()` 内。
   - `SurfacePbr`：62 材质最终参数（含 water/glass/ice/crystal/metal/slab/rust/concrete 的族内微调）、`PbrAlpha`（Opaque/Cutout/Blend）与 catalog emission 档。
   - 程序化地图（与 albedo 共用 16×16 网格/UV）：`build_normal_map`（亮度→Sobel→单位切空间向量，强度按家族烘焙）、`build_orm_map`（R=255 不烘 AO、G=roughness、B=metallic）、`build_emission_map`（仅 emission 材质的亮度 mask；HDR tint 在材质上）。
   - `pbr_audit()`：家族范围/非金属归零/emission 档合法性；`write_pbr_audit` 输出 `target/art-audit/pbr-families.json`。
2. 发布材质接入（`materials.rs`）：`TerrainMaterials` 增加 `orm_atlas`（Rgba8Unorm、Nearest、与 albedo 同 UV），`solid` 绑定 `metallic_roughness_texture` 且 `metallic=1.0`/`perceptual_roughness=1.0`（值全部来自纹理）；normal/emission 未接入世界（normal 需要 C02 的顶点切线；emission 归 D04/H04）。
3. `visual_qa` B04 场景（`SceneId::B04`）：13 家族 × 球/方块/斜坡/薄片/室内物件 5 形态 + 一间带灯房间；9 机位覆盖正午/阴天/暖夕阳/夜灯/室内与金属/岩石/木材/发光近景。`FamilyMaterials` 为每家族用代表 tile 生成 albedo/normal/ORM/emission 四图并 `generate_tangents()`，使法线在庭院里真实生效；`ScenePose.day_time` 支持逐 pose 光况，`LightingProbeMode::Overcast`（sun 0.35 / ambient 1.15 / environment 1.0）新增；manifest schema 4→5。
4. `--texture-audit` 扩展为纹理+PBR 联合审计（`TEXTURE_AUDIT_PBR`），退出码包含 PBR 失败。
5. 文档：`art/style-guide.md` §3.3（家族参数/地图通道/发布接入/庭院判读）。

## 兼容、回滚与故障注入

- 存档/网络/设置/依赖：零变化；`Cargo.toml`/锁文件、`SAVE_VERSION`、材质 ID、方块 ID 均未动。ORM 是纯视觉材质变更，不改变世界数据。
- 观测：`--texture-audit` 额外写 `pbr-families.json` 并打印 `TEXTURE_AUDIT_PBR`；B04 manifest 增加可选 `poses[].day_time`（附加字段）；capabilities/诊断不受影响。
- 回滚：删除 `src/art/pbr.rs`、还原 `TerrainMaterials::build` 的 ORM 参数与绑定、移除 B04 场景/FamilyMaterials/Overcast 探针即可；无数据迁移。
- 已注入/已覆盖：平坦法线、高度台阶、零向量、全黑 emission、亮 emission、非金属 metallic=0、家族范围越界（用于 audit 失败路径的参数组合）、alpha 三分类、图集单元格对齐、低端 array fallback（B03 仿真）。
- 未注入：真实 GPU 上的地形法线贴图（需要 C02 顶点切线，当前绑定会被 `#ifdef VERTEX_TANGENTS` 跳过，因此未绑定世界）、设备丢失、非本机 GPU 的金属环境反射差异。
