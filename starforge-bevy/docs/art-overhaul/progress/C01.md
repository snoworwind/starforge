## 交付内容

1. **MeshBuilder 入口（行为保持）**：`world::ChunkMeshBuilder` 持有 `world/chunk/atlas` 与 solid/water 缓冲区，`build()` 内含原 `build_chunk_meshes` 循环；`build_chunk_meshes` 变为一行薄包装。C02+ 可在 `build()` 内分桶/UV/tangent/AO/贪婪合面，调用点不变。
2. **固定网格 hash 回归**：`VoxelMesh::signature()`（FNV-1a，逐 f32 位 + 索引）冻结两个黄金值：
   - `World::new(11, "lush", 3)` chunk(0,0) solid：`0x8c94ec552c4ed9ca`，6576 顶点（无水面网格）；
   - `World::new(11, "ocean", 3)` chunk(0,0) water：`0x8ac2bf217cc775ad`，1248 顶点。
   另有单测证明放置方块后签名变化（防止“hash 恒定但忽略输入”）。
   - **重构前后对照证据**：在 `c6f0c1d` 的临时 git worktree（共享 target，仅重编 crate）里运行等价的探针测试，得到完全相同的两个 hash（`BASELINE_LUSH solid=0x8c94ec552c4ed9ca verts=6576`、`BASELINE_OCEAN water=0x8ac2bf217cc775ad verts=1248`），随后 worktree 已删除。
3. **地形输入/覆盖诊断**：`src/terrain/`（新）
   - `TerrainDiagnostics`（Resource + Serialize）：near（view_dist、生成/网格/卸载环、驻留区块、solid/water 网格、实体数、view 内缺网格/脏块数）、LOD（coverage_ready、半径 16384、levels 2..8、`LodStats`、逐层直方图、epoch）、far（present/visible/中心/seed/epoch/staging/半径 1536/下沉 2.2）、curvature（星球半径、flat 256、full 1500、focus/datum）、ownership 四段（near/LOD/far/curvature）与 `dirty_chunks_sample`（≤32）。
   - `input_signature(seed, biome, view_dist)`：含 `WORLD_H`/`PLANET_SCALE`/LOD/FAR 常量，用于区分“世界输入变了”还是“网格实现变了”。
   - `notes` 明确写入 C01 风险结论：**LOD 是地表近似，不覆盖洞穴/桥梁/悬挑/高塔**；legacy far 与 LOD 环为有意的 fallback 重叠；本包不改变选择逻辑。
4. **可视化**：`--terrain-overlay`（A06 `LaunchOptions`）+ `TerrainOverlay` 资源（默认关）。开启后 gizmos 绘制：近区块矩形（脏块红、正常青）、LOD 分层矩形（青→琥珀按 level）、legacy far 范围（绿）、曲率 flat/full 圆环（琥珀/品红）。关闭时系统在生成任何 gizmo 前返回。
5. **LOD 只读接口**：`LodRuntime::node_views()`（按键排序，确定性）、`level_histogram()`、`world_epoch()`；`LodStats` 增加 `Serialize/PartialEq`；公开 `COVERAGE_RADIUS_METERS`、`LEVEL_RANGE`。
6. **visual_qa 接入**：`metrics.json` 增加 `terrain` 快照（`TerrainDiagnostics`），沿用 A01 的 scene/run 目录，不新增第二套报告。

## 兼容、回滚与故障注入

- 存档/协议/依赖：零变化；`world.rs` 的 RLE/结构/流式逻辑未动，仅搬移网格函数体并加只读接口。
- 默认行为：`TerrainPlugin` 每帧只做计数/直方图快照（微秒级），不改变流式/LOD/far 选择；`--terrain-overlay` 默认关闭。
- 回滚：删除 `src/terrain/`、`--terrain-overlay` 接线与 metrics 字段；`ChunkMeshBuilder` 可还原为原函数（hash 测试会守住差异）。
- 故障注入/边界：signature 在编辑后必须变化（单测）；input_signature 对 seed/biome/view_dist 敏感且可复现（单测）；覆盖带顺序/来源（单测）；overlay 默认关闭与闭环几何（单测）。
- 实施中发现的坑：共享 `CARGO_TARGET_DIR` 的 baseline worktree 会让 cargo 复用同包名旧测试二进制（曾出现 222 测试的假结果），已用 `cargo clean -p starforge-bevy` 复位并重跑；后续跨 worktree 编译不得共享 target 目录。
