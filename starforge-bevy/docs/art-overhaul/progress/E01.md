## 交付内容

1. `src/weather/` 目录拆分（00.3 规划的 weather 落点）：
   - `weather/mod.rs`：原 `weather.rs` 内容（行为等价，`main.rs` 的 `mod weather;` 不变），新增 `debug: Vec4` uniform 字段、密度统计与诊断系统接线。
   - `weather/diag.rs`：E01 诊断契约与 CPU 数学（新增）。
2. CPU 球壳区间模型（与 `cloud_shell.wgsl` 的 `ray_sphere`/`shell_interval` 同构，并补上被单区间实现丢弃的远侧段）：
   - `ray_sphere` 命中/背离/切线（disc<0、根为负、NaN 处理）；
   - `shell_intervals` 返回 `camera_region`（Below/Inside/Above）、shipping 的 `first` 段、被丢弃的 `far` 段与 `camera_inside_outer`（背面裁剪判据）；
   - `truncate_to_scene`：天空 depth=0 不截断、几何命中截断、命中在区间前返回空（R053）；
   - `composite_premultiplied`：`L + T*background`，与材质 `AlphaMode::Premultiplied` + `out.color=(radiance, 1-T)` 的契约一致；
   - `density_threshold/density_remap`：与 shader `mix(0.62,0.18,coverage)` + smoothstep 侵蚀一致；`DensityStats` 统计 3D 纹理。
3. `CloudDiagnostics`（每帧、Serialize，写入 `metrics.json` 的 `clouds` 块）：
   - 生效值从**实时 material uniform 回读**：coverage/density/steps；与 `CloudTuning` 请求值并列，杜绝“设置写了但没生效”（R061/R117）；
   - `legacy_render_resolution`（1536×864）与 `effective_render_resolution`（真实 viewport）并列，并显式 `render_resolution_inert=true`：确认该字段为保存兼容字段、不改变任何渲染目标；
   - shell 内外高度、中心射线模型、密度纹理统计、debug 模式、notes（含“单区间丢弃 far，E04 决定”）。
   - 密度统计在纹理生成时一次算完（1,179,648 体素），不每帧重扫。
4. Shader 诊断视图（`cloud_shell.wgsl`，uniform `debug.x`）：density、interval、transmittance、scattering、steps、depth（截断前后）、light、faces（绿=保留面/红=剔除面），0 为原路径；所有 debug 输出不透明，避免背景混色。
5. `--cloud-debug` CLI（app 统一解析，只读不落盘）与 `SceneId::E01` 云壳诊断矩阵：
   - 12 个机位覆盖云下（180）、贴底（415）、云内（600）、云上（1050）、背离仰视、切线俯冲；同机位配对 shipping 与 debug 视图；
   - 每个 `CaptureRecord` 附 CPU 区间的 `cloud_region/first/far`；抓图延后一帧，使 A02 `Last` 快照与所截机位一致（原 D01 抓图在换机位当帧，云字段会滞后一个机位）；
   - 场景结束把 `CloudDebug` 复位为 Off，不泄漏给同轮后续场景。
6. 实施中发现的资产路径坑（影响所有 QA 复现）：
   - 开发构建的 `target/debug/assets` 只在“缺必发文件”时复制；E01 修改的是已存在 shader，导致 exe 一直渲染旧云。已改为：shaders 组在**字节不同**时刷新，models 仍只在缺文件时复制（不重拷数百 MB），并新增单测 `bootstrap_refreshes_changed_shaders_without_recopying_models`。
7. 文档/署名路径修正：README 目录树与云说明、CREDITS 的 `weather/mod.rs`。

- 已注入/已覆盖：非法 `--cloud-debug`；背离/切线/负根/切线判别式；天空 depth=0 与几何命中截断；debug 模式场景结束复位；同轮 D01/S01/S02 回归。
